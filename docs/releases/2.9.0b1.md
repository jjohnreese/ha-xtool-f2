# v2.9.0b1 — regular F2 firmware 40.56.025.00.ht4

New-firmware prerelease for the regular **F2 GS006**. The preserved older
firmware build remains [v2.8.3](https://github.com/jjohnreese/ha-xtool-f2/releases/tag/v2.8.3)
for **40.56.024.00.ht3**. Neither tag replaces the other.

Changes:

- Pairing-token persistence, explicit confirmation/reauthentication and a
  per-connection session token for the ht4 protocol.
- Authenticated heartbeat and temporary Repeat connections, token rotation
  handling and redacted authentication logs.
- The existing separate Repeat last job button supports exact ht4 as well
  as ht3, preserving state/alarm/digest guards, transfer-channel cleanup,
  disabled auto-start/looping and one Start without automatic retry.
- F2 exhaust status now follows the already-polled exhaust output
  `ext_purifier.state`, including automatic transitions. Other models do
  not inherit this F2-specific mapping.
- Stop creating Device sleep for GS006: both `autoSleepEnable` writes fail
  on ht4. Disable any retained older entity; no machine setting is changed.
- Preserve the owner's pause-state fix and wireless-button examples.
- Add a firmware/release compatibility table, pairing/install/rollback
  guidance, control/event semantics, troubleshooting and validation limits.

Validation: **39 offline regression tests pass**, and Python 3.12
compilation succeeds. Home Assistant **2026.11.1**, one regular F2 on
**40.56.025.00.ht4**, 2026-11-12. The local authentication candidate paired
successfully; Start/Pause/Resume transitions were observed, and the owner
confirmed two consecutive separate Repeat presses each ran the same job
once. Both starts and completions were recorded without the prior
transfer-channel failure. Software checks cover the additional fan mapping.

Post-publication verification: the owner-repository package was installed
through Marketplace; all **71 component files matched commit 0b1e060**.
After restarting Home Assistant, the F2 reconnected using its saved pairing,
the fan sensor reported an on/off value, Device sleep was disabled/hidden,
and no xTool startup errors were reported. Enabling this repository's
prerelease channel removed the misleading default-branch update offer.

A fresh physical repeat/fan-transition check after that final installation
remains pending owner confirmation; the two confirmed repeats above used
the earlier local authentication candidate. No physical fire or fault test
was performed. Other devices/firmware are outside this test scope.
See [the complete F2 guide](../F2-firmware-and-controls.md).
