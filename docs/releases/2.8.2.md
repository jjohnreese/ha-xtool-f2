Fixes the second-repeat failure caused by metadata transfer channels being
left occupied on the F2. The initial single physical repeat passed, but
the following press could fail with `code -1: channel is busy`.

Each successful metadata request now has explicit cancellation in a
finally block. Closing Wi-Fi alone is insufficient. Cleanup uses the
regular-F2 firmware's nonzero finish-code path (`cancel_transfer`),
without downloading or changing the design. A rejected/busy channel is
never cancelled because another client may own it.

Validation: 19 regression tests pass, including consecutive completed jobs,
cleanup after invalid metadata, cleanup failure, and refusing to cancel a
channel this request did not acquire. Nine consecutive metadata checks
across three actual F2 sessions reused the same channels successfully,
with identical fingerprints and no job/start commands.

This candidate is being installed through HACS from jjohnreese/ha-xtool-f2.
Consecutive physical repeats must pass before this release becomes stable.
Verified environment: regular F2 GS006, firmware 40.56.024.00.ht3;
Home Assistant 2026.10.4. Other models/firmware are outside the repeat scope.
