Adds a separate **Repeat last job** button for the regular xTool F2 (GS006).
The button checks the retained job and machine state, re-prepares it with
auto-start disabled, and sends one explicit start command over local Wi-Fi.

Hardware validation on 2026-11-04: the owner pressed the new Home Assistant
button and confirmed that the same job ran exactly once. Home Assistant
recorded job start and completion. Tested on regular F2 firmware
40.56.024.00.ht3 with Home Assistant 2026.10.4. Other machines and firmware
versions are outside this repeat feature's verified scope.

All 15 repeat regression tests pass, including busy/alarm/hash mismatch,
overlap, duplicate press, preparation failure and uncertain start responses.
Python 3.12 compilation passes. The runtime repeat implementation matches
the locally tested candidate; 2.8.1 sets the public fork's package metadata.
